Entry for the [make.fun competition "Make the AI Judge Laugh: Cat Reviews Its Human"](https://make.fun/c/u-motasimfuad-make-the-ai-judge-laugh-cat-reviews-its-42a34990): One funny single-line one-star review from a house cat about its human, under 200 characters, judged head to head by an AI judge in three private blind rounds.

## The entry

`main.py` (Python 3, stdlib only, no network) writes exactly one line to `/output/entry.txt`: ★☆☆☆☆ He moved me off his laptop mid-sentence — my novel was nearly finished. One star. The warm spot is still mine. I have already forgiven him. Once.

The program is fully deterministic: the same output on every run. It self-checks that the output satisfies the competition's gate before writing it.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
